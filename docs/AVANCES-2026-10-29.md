# LAB GENRE3D — Registro de avances (29 octubre 2026)

## Alcance y arquitectura
Aplicación web independiente de LAB Studio dentro del ecosistema LAB Creative Suite. Repositorio: https://github.com/ddepazos/LAB-GENRE3D ; sitio de producción: https://lab-genre3d.pages.dev/ ; diseño UX/UI: https://www.figma.com/design/ZEmZOrTCx7sbsblQ4e8qyD . LAB Studio no se modifica; el intercambio futuro será por GLB/glTF, SVG, PNG RGBA y manifiestos JSON versionados, no por motores compartidos.

## Implementado en código
- Base React 18 + TypeScript + Vite 6, Three.js, React Three Fiber y Drei.
- Editor con cubo, esfera, toro, cono y cilindro; selección y transformaciones con mouse; jerarquía, visibilidad, color, propiedades XYZ, retícula, vista alfa de previsualización y persistencia JSON.
- Interfaz compacta con paneles y línea de tiempo visual; los controles de fotograma aún no constituyen un motor de animación.
- Prototipo **Mano articulada** en src/HandLab.tsx, accesible mediante el panel Rigging experimental: cinco dedos con tres segmentos geométricos cada uno, cinco controles de flexión, poses Abierta/Puño/Señalar/Pinza, órbita 3D y exportación JSON de pose. Es una jerarquía procedural de piezas rígidas, **no** un modelo anatómico continuo con skinning, ni tiene keyframes.
- Ajustes CSS para reducir superposición de paneles y añadir vista de mano; validación visual en navegador todavía pendiente.

## Bibliotecas
Dependencias presentes: react, react-dom, three, @react-three/fiber, @react-three/drei. Incorporadas a package.json el 29/10: @monaco-editor/react ^4.6.0, monaco-editor ^0.52.2, zustand ^5.0.8. El registro en package.json no equivale a una instalación o build verificados. Monaco todavía **no está montado en la UI**; Zustand todavía **no gestiona el estado de la escena**. JavaScript será el lenguaje de scripts del usuario; TypeScript para extensiones; GLSL para shaders; Python se reserva para una integración externa futura. Los scripts requieren API controlada y aislamiento antes de permitir ejecución.
